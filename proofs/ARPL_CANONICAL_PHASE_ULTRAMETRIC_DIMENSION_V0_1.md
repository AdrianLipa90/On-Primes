## 1. Strict refinement scales

The cumulative clock sizes

\[
L_N=\operatorname{lcm}(e_{p_1},\dots,e_{p_N})
\]

are non-decreasing and tend to infinity.

Remove repeated values and write the strictly increasing cofinal subsequence as

\[
1=M_0<M_1<M_2<\cdots,
\]

with

\[
M_k\mid M_{k+1}
\]

and

\[
M_k\to\infty.
\]

The phase hull is equivalently

\[
K_h
\cong
\varprojlim_k
\mathbb Z/M_k\mathbb Z.
\]

## 2. Canonical arithmetic ultrametric — OP-D148

For distinct

\[
x,y\in K_h,
\]

let

\[
n(x,y)
=
\max\{k\ge0:x\equiv y\pmod{M_k}\}.
\]

Define

\[
\boxed{
d_h(x,y)=\frac1{M_{n(x,y)}}
}
\]

for \(x\ne y\), and

\[
d_h(x,x)=0.
\]

Equivalently, two phase points are close when they agree to a high finite clock resolution.

Because agreement modulo \(M_k\) is an equivalence relation nested in \(k\),

\[
n(x,z)
\ge
\min\{n(x,y),n(y,z)\}.
\]

Therefore

\[
\boxed{
d_h(x,z)
\le
\max\{d_h(x,y),d_h(y,z)\}.
}
\]

Thus \(d_h\) is an ultrametric.

It generates the inverse-limit topology on \(K_h\).

## 3. Balls are phase cylinders — OP-D149

Fix \(x\in K_h\).

The level-\(k\) residue cylinder

\[
[x]_{M_k}
=
\{y\in K_h:y\equiv x\pmod{M_k}\}
\]

is exactly the closed/open ultrametric ball at the corresponding canonical scale.

Up to the harmless index convention at the boundary radius,

\[
\boxed{
B_k(x)=[x]_{M_k}.
}
\]

Its Haar measure is

\[
\boxed{
m_{K_h}(B_k(x))
=
\frac1{M_k}.
}
\]

Its diameter in the canonical metric is

\[
\boxed{
\operatorname{diam} B_k(x)
=
\frac1{M_k}.
}
\]

Thus measure and phase-resolution scale coincide exactly.

## 5. Hausdorff dimension — OP-D151

### Upper bound

Cover \(K_h\) by its \(M_k\) level-\(k\) cylinders.

For \(s>1\), the \(s\)-dimensional Hausdorff content at this scale is

\[
M_k
\left(\frac1{M_k}\right)^s
=
M_k^{1-s}
\to0.
\]

Therefore

\[
\dim_H(K_h)\le1.
\]

### Lower bound

Haar measure satisfies the exact Frostman bound

\[
m(B)=\operatorname{diam}(B)
\]

on every metric ball.

The mass-distribution principle therefore yields

\[
\dim_H(K_h)\ge1.
\]

Consequently

\[
\boxed{
\dim_H(K_h,d_h)=1.
}
\]

The same cylinder count gives upper and lower box dimension equal to \(1\).

Thus

\[
\boxed{
\dim_{\rm box}(K_h,d_h)=1.
}
\]

## 6. Information dimension — OP-D152

\[
\varepsilon_k=\frac1{M_k},

Its Shannon entropy is

\[
H_k=\log M_k.
\]

Therefore

\[
\boxed{
\frac{H_k}{\log(1/\varepsilon_k)}
=
\frac{\log M_k}{\log M_k}
=
1.
}
\]

Hence the Haar information dimension in this canonical phase metric is exactly

\[
\boxed{
D_{\rm info}=1.
}
\]

This is the metric-information dimension of the phase hull, not thermodynamic entropy.

## 11. Metric dependence firewall

Hausdorff dimension depends on the metric.

The value

\[
\dim_H=1
\]

proved here belongs specifically to the canonical arithmetic metric with phase radius

\[
\varepsilon_k=M_k^{-1}.
\]

A different assignment of geometric radii to refinement levels can produce a different Hausdorff dimension.

Therefore the theorem is:

\[
\boxed{
\dim_H(K_h,d_h)=1
}
\]

for the explicitly defined canonical metric, not an unqualified metric-free claim of “fractal dimension one.”
