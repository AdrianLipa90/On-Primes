# Complete Prime-Mask Characterization v0.1

Fix odd \(a\ge1\) and
\[
x_{a,k}=a2^k-1.
\]
Assume first \(k\ge1\), so \(x_{a,k}\) is odd.

For an odd prime \(r\):

- if \(r\mid a\), then \(x_{a,k}\equiv-1\pmod r\), so \(r\nmid x_{a,k}\);
- if \(r\nmid a\), then
  \[
  r\mid x_{a,k}
  \iff
  2^k\equiv a^{-1}\pmod r.
  \]

If \(a^{-1}\) lies in the subgroup generated by 2 modulo \(r\), there is a unique residue class
\[
k\equiv k_{a,r}\pmod{d_r},
\qquad d_r=\operatorname{ord}_r(2),
\]
that gives divisibility by \(r\). Otherwise \(r\) contributes no obstruction class.

## Theorem — exact complete mask

For \(x_{a,k}>1\),
\[
\boxed{
x_{a,k}\in\mathbb P
\iff
\text{no prime }r\le\sqrt{x_{a,k}}
\text{ divides }x_{a,k}.
}
\]
Translated into fibre coordinates, for \(k\ge1\),
\[
\boxed{
M_a(k)=1
\iff
\forall\ r\le\sqrt{x_{a,k}}\ \text{odd prime},
\quad
k\not\equiv k_{a,r}\pmod{d_r}
}
\]
where primes \(r\mid a\) and primes for which no obstruction class exists are ignored.

Equivalently, defining
\[
H_{a,r}(k)=
\begin{cases}
0,& r\mid x_{a,k},\\
1,& r\nmid x_{a,k},
\end{cases}
\]
the prime mask admits the finite factorization
\[
\boxed{
M_a(k)
=
\prod_{\substack{r\le\sqrt{x_{a,k}}\\r\ \mathrm{prime}}}
H_{a,r}(k)
}
\]
with the usual separate handling of values \(x_{a,k}<2\) and the even boundary.

## Boundary

For \(k=0\), \(x_{a,0}=a-1\) is even. The only prime case is \(a=3\), giving \(x=2\). This agrees with the previously proved boundary theorem.

## What this does and does not solve

This is an **exact characterization** of the prime mask as an intersection/product of periodic modular masks.

It does not provide a new polynomial-time primality algorithm or a new asymptotic law: the set of required divisor primes grows with \(\sqrt{x_{a,k}}\), and determining the global pattern of simultaneous avoidance remains the hard distribution problem.

Nevertheless it upgrades the finite-sieve view from a necessary condition to a complete combinatorial description at every fixed fibre site.
