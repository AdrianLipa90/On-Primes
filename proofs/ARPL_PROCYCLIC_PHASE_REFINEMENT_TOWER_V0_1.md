Status: exact inverse-limit representation of the global base-4 phase clock. The group-theoretic machinery is standard; the specialization to the ARPL channel periods is project-specific.

## 1. Active channels and finite clocks

Fix an admissible base separation

\[
h\ge6,\qquad 6\mid h.
\]

Enumerate the active odd-prime channels as

\[
p_1,p_2,\dots
\]

in any fixed order. For each active channel define

\[
e_j
=
e_{p_j}
=
\operatorname{ord}_{p_j}(4),
\]

and its unique pulse phase

\[
\rho_j
=
\rho_{p_j}(h)
\pmod{e_j}.
\]

For \(N\ge1\), define the cumulative clock

\[
\boxed{
L_N
=
\operatorname{lcm}(e_1,\dots,e_N).
}
\]

Then

\[
L_N\mid L_{N+1}.
\]

## 2. Finite diagonal phase group — OP-D110

Define the finite diagonal orbit

\[
K_{h,N}
=
\left\{
(r\bmod e_1,\dots,r\bmod e_N):
r\in\mathbb Z
\right\}
\subset
\prod_{j=1}^N\mathbb Z/e_j\mathbb Z.
\]

The homomorphism

\[
\theta_N:
\mathbb Z\to K_{h,N},
\qquad
r\mapsto(r\bmod e_j)_{j\le N}
\]

has kernel

\[
L_N\mathbb Z.
\]

Therefore the first isomorphism theorem gives the canonical cyclic-group isomorphism

\[
\boxed{
K_{h,N}
\cong
\mathbb Z/L_N\mathbb Z.
}
\]

In particular,

\[
|K_{h,N}|=L_N.
\]

## 3. Exact refinement factor — OP-D111

The natural projection

\[
K_{h,N+1}\to K_{h,N}
\]

corresponds under OP-D110 to reduction modulo \(L_N\),

\[
\mathbb Z/L_{N+1}\mathbb Z
\to
\mathbb Z/L_N\mathbb Z.
\]

Every phase state at level \(N\) therefore has exactly

\[
\boxed{
b_N
=
\frac{L_{N+1}}{L_N}
=
\frac{e_{N+1}}{\gcd(e_{N+1},L_N)}
}
\]

lifts at level \(N+1\).

Thus:

- \(b_N=1\): the new channel adds no new clock resolution;
- \(b_N>1\): every old phase cell splits uniformly into \(b_N\) refined cells.

The refinement number is arithmetic and exact.

## 5. Uniform Haar refinement — OP-D113

Haar probability measure \(m_{K_h}\) projects to uniform counting measure on every finite quotient:

\[
\boxed{
(\pi_N)_*m_{K_h}
=
\frac1{L_N}
\sum_{r=0}^{L_N-1}
\delta_r.

\]

Therefore each level-\(N\) phase cell has measure

\[
\frac1{L_N},
\]

\[
\frac1{L_{N+1}}.
\]

Thus the refinement tower preserves probability exactly.

## 6. Generalized-CRT pulses are cylinder sets

For channel \(p_j\), the special-hit event is

\[
r\equiv\rho_j\pmod{e_j}.
\]

On \(K_h\), define the cylinder

\[
C_j
=
\{x\in K_h:x_j=\rho_j\}.

Then

\[
m_{K_h}(C_j)
=
\frac1{e_j}.
\]

For a finite set \(J\) of active channels,

\[
C_J=\bigcap_{j\in J}C_j.

The cylinder is empty exactly when the phase congruences are incompatible. If compatible, it is one residue class in the finite clock of size

\[
L_J=\operatorname{lcm}_{j\in J}e_j,

so

\[
\boxed{
m_{K_h}(C_J)
=
\delta_J(h)
=
\frac1{L_J}.

\]

Thus all ARPL finite joint densities are literally Haar cylinder measures.

## 8. Exact phase-refinement graph — OP-D115

\[
\boxed{

## 9. Finite versus genuinely infinite refinement

The following are equivalent:

1. \(K_h\) is finite;
2. the sequence \(L_N\) eventually stabilizes;
3. \(b_N=1\) for all sufficiently large \(N\).

If \(L_N\to\infty\), then \(K_h\) is infinite and Haar measure on \(K_h\) is non-atomic.

This statement concerns the source phase hull. The pushforward amplitude/log law may still have atoms if the phase observable is constant on a positive-Haar-measure set.

Therefore atomlessness of \(\nu_h\) does not follow merely from infinitude of the hull.
